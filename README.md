# Anas Nihal — Portfolio

A responsive portfolio for Ahammed Anas Nihal, a full-stack developer and product engineer based in Kerala, India. The site brings together selected product work, AI engineering, and creator content in an editorial layout inspired by mijobello.com.

## Stack

- React 19
- Vite 7
- Plain CSS with responsive layouts and scroll-driven motion
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Create a production build with `npm run build`, or preview it locally with `npm run preview`.

## Site features

- Responsive layouts, mobile navigation, and reduced-motion support
- Light and dark themes, with the selected theme saved in local storage
- Animated opening, rotating hero photography, and scroll-driven biography photo
- Interactive project carousel and expandable project archive
- Instagram reel cards that link to the original videos

## Content and assets

Personal details and project descriptions are based on the supplied résumé and public project repositories. Personal photography and the Nexentcorp and Solar1 ERP screenshots were supplied for this portfolio. Other project illustrations were created for the site.
